## T13 — landed `de11948`, but **NOT code-reviewed**

All four blockers closed, 66 new tests, 12 mutations caught. Suite **1089 passed / 2 deselected**.
It is the only task in this push that went in without a review pass (context budget), and it is
also the highest-risk one — it decides whether an overnight run produces anything. **Review it
before trusting an unattended run.**

### The launch command — the env var is NOT optional

T13's launcher kwarg only reaches **relaunched** bridges. The pads a run connects to are booted
earlier by `start-pads.sh`, which passes no such flag. Without the env var every opponent stays
knockback-immune and speed-0, and **every log looks healthy**:

```bash
DUMMY_KNOCKBACK_IMMUNE=false server/setup/start-pads.sh --pads 25
.venv/bin/python -m agent.train --arenas 25 --opponent scripted \
  --warm-start runs/m2_multi.pt --checkpoint runs/m3.pt \
  --checkpoint-every-grad-steps 1000
```

Verify by hitting an opponent and watching it move — never from the datapack's `tellraw`.

**The EASY-only cut needs BOTH** `--opponent-mix-easy 1.0` and `--opponent-mix-easy-after 1.0`.
`mix_easy` alone holds only until the gate fires, after which the mixture shifts to 0.2 and HARD
becomes the majority tier — the opposite of the intended cut.

New flags for T15's docs: `--warm-start`, `--warm-start-eps-start`, `--opponent-mix-easy`,
`--opponent-mix-easy-after`, `--opponent-gate-winrate`, `--opponent-gate-window`,
`--eval-opponent-preset`, `--stop-on-pass`/`--no-stop-on-pass`, `--best-checkpoint`,
`--checkpoint-every-grad-steps`.

### Two known edges T13 disclosed

- A **pre-existing race** in `distributed/actor.py::_wait_while_paused` — `_paused_idle` is set
  once before the wait loop, so a `resume()`→`pause()` inside the 10 ms wake window costs one
  eval cycle. Self-heals. Test-only in practice at the 1000-grad-step cadence.
- The **final save runs after `learner_thread.join(timeout=5.0)`**, which can return with the
  thread alive, so it may read a live `state_dict`. Same risk as the pre-existing improvement-time
  save. Known edge, not an oversight.
