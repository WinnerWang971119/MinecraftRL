### Warnings being fixed before launch

  `DRQNGreedyPolicy` holds `trainer.online` by reference and the learner keeps stepping

- **W5** — two surviving mutations, both real test gaps: deleting the warm-weight
  `weight_store.publish(..., 0)` survives the whole suite, and the eval opponent's

### Launch conditions from the review

1. Boot the fleet with `DUMMY_KNOCKBACK_IMMUNE=false`. Verified to work; no substitute.
2. Pass `--checkpoint`. **Never `--best-checkpoint` alone** (W4).
3. For the EASY-only cut, pass **both** `--opponent-mix-easy 1.0` and
   `--opponent-mix-easy-after 1.0` — the reviewer confirmed this document was right.
   Pair it with `--eval-opponent-preset easy` (N1): the eval preset defaults to `mixed`,
   so half the selection signal would score a tier the agent never trained against.
4. **W2 — lower `--eval-episodes`.** It defaults to **100**, run serially on one arena:
   roughly half an hour of wall clock, against ~10-15 minutes per 1000 grad steps. The
   next eval fires almost immediately after the previous ends. Recommend ~20-30.

## Smoke run — the measured numbers that set the launch config

25 pads, warm start, eval off, 400 grad steps. Clean exit:
`reason=max_grad_steps episodes=519 grad_steps=400 checkpoints_saved=1`. The final
save with `--eval-every-grad-steps 0` is T13's blocker 2 confirmed **live**, not in a test.

| Quantity | Assumed | **Measured** |
|---|---|---|
| Mean episode length | 30 steps | **285** (cap `MAX_EPISODE_STEPS=400`) |
| Grad steps/hour | unmeasured | **1188** avg incl. replay fill; **~1800** steady state |
| Episodes/hour (25 pads) | — | **1542** |
| Episodes in 12h | 175,615 | **~18,500** |
| One eval at `--eval-episodes 100` | "~30 min" | **97 min** |

**The ε default was wrong by 9.5x in the dangerous direction.** `eps_decay_episodes=26342`
spans **142% of a 12h run**, so ε would never finish decaying and would sit near 0.25 all
night. T16's formula was sound; its `ASSUMED_MEAN_EPISODE_STEPS = 30` was not, because the
only measured figure in the repo (17.0) came from a greedy eval against a **stationary**
dummy. Against a HARD bot that flees at 6 HP, fights drag toward the timeout.
Correct value at 15% of the run: **2775**.

**The curriculum gate fires at grad_step 0**, win_rate 0.76 over 50 EASY episodes. The
warm-started agent already beats EASY, so the run spends the night on HARD. Intended.
