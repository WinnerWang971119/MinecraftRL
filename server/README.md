# server/

Paper Minecraft server setup for the training arena. Contains launch scripts,
arena world configuration (flat arena, fixed gear/spawn points, minimal
view/sim distance, no mob spawning), ops configuration, and the day-1
version-compatibility check documentation.

The server runs in offline mode with opped bot accounts so bridge bots can issue
`/tp`, `/effect clear`, and regear commands.

**Owner workstream:** Environment/bridge track
